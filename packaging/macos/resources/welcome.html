Omelet runs your docker-compose projects inside a Linux virtual machine and hands you back a web address on this Mac.

This installer copies the app into your Applications folder and puts the omelet command on your PATH. It does not create the virtual machine — you do that afterwards, from the Omelet app, and it takes several minutes.

Before you start: Omelet drives Lima, which is not bundled yet. If you do not have it, install it first with brew install lima. Setup will tell you the same thing if it is missing.
