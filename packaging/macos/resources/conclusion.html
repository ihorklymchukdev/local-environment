Omelet is installed, but it has nothing to run yet.

Open Omelet from your Applications folder to build the virtual machine. It downloads a Linux image and installs Docker inside it, which takes several minutes on a first run.

If you prefer the terminal, omelet setup --headless does the same thing and prints its progress.

To remove everything later, including the virtual machine and every project inside it, run omelet uninstall --purge and then drag Omelet to the Trash.
